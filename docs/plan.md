# CubeRubikAi: план работ

Описание - в `spec.md`. Задачи идут по порядку, каждая заканчивается зелёными тестами и коммитом. Образец устройства - `DurakAiGame`.

## Этап 1. Модель и решатели

1. **Каркас** по контракту: git, MIT, README EN/RU, pytest, CI на Gitea и GitHub.
2. **Модель куба** `game/core/cube.py`: N×N из геометрии (наклейки как точки, ход как поворот на 90°), запись ходов, кубики 3×3 и проверка возможности состояния. Законы: ход 4 раза, ход и обратный, порядки, коммутаторы; мутационная проверка.
3. **Kociemba** `game/ai/kociemba.py`: таблицы ходов и отсечения в numpy, файл в папке данных, построение с прогрессом; поиск в две фазы с улучшением до лимита времени.
4. **2×2 полным перебором**: расстояния до сборки для всех 3 674 160 позиций.

## Этап 2. Окно

5. **Отрисовка 3D** на QPainter: кубики, сортировка по глубине, плавные повороты; вращение мышью без захвата курсора, поворот слоя перетаскиванием, клавиши.
6. **Режимы** «Собираю сам» (таймер, история, отмена, рекорды) и «ИИ собирает» (шаги, пауза, назад, вперёд, скорость), «Мысли ИИ».
7. Темы, RU/EN, место окна, тесты окна offscreen, кадры.

## Этап 3. Сеть

8. **Сеть по идее DeepCubeA**: оценка «сколько ходов осталось», итерация ценности на перемешанных позициях, взвешенный A*. Пробный прогон с прогнозом времени, потом обучение по команде.
9. **Паспорт**: Kociemba и сеть на 1000 случайных кубиках (доля, длина, время), сеть против оптимума на 2×2.

## Этап 4. Учёба и свой кубик

10. «Учусь»: послойный метод правилами, шаги словами и подсветка кубиков.
11. «Свой кубик»: ввод цветов на развёртке, проверка «кубик разобран неправильно».

## Этап 5. Выпуск (только после «да» Алексея)
