# CubeRubikAi: кубик Рубика, который собирает ИИ

Игра из ИИ-Игротеки на Python. Общие правила — `C:\Work\PythonAiGames\docs\contract.md`, очередь — волна 5.

## 1. Что это

- **3D-кубик 3×3** (плюс 2×2 и 4×4 как опция):
  - крутится мышью: вращать весь куб, тянуть грань;
  - клавиши в нотации U D L R F B с ' и 2;
  - плавные повороты.
- **Отрисовка.** Своя 3D-проекция на QPainter (26 кубиков, сортировка граней по глубине) или QOpenGLWidget. Выбирает агент. Тесты отрисовки — offscreen.
- **Режимы:**
  - **Собираю сам:** таймер, история, отмена хода, рекорды.
  - **ИИ собирает:** перемешать или ввести своё состояние, затем ИИ показывает решение по шагам. Пауза, назад, вперёд, скорость.
  - **Учусь:** послойный метод для начинающих. ИИ объясняет каждый шаг словами: «собираем крест», «ставим уголки» и подсвечивает нужные кубики.
  - **Свой кубик:** ввести цвета с развёртки мышью. Проверка, что такое состояние возможно: чётность, ориентации, иначе подсказка «кубик разобран неправильно». Камера — потом, опция.

## 2. ИИ

1. **Kociemba, двухфазный.** Точный алгоритм: решение в среднем около 20 ходов за доли секунды. Таблицы отсечения считаются в numpy и сохраняются в файл; если их нет, строятся при первом запуске с прогрессом.
2. **Обученная сеть, по идее DeepCubeA.**
   - Сеть на numpy оценивает, сколько ходов осталось до сборки.
   - Учится на позициях, перемешанных от собранного назад (k ходов), с итерацией ценности.
   - Поиск — взвешенный A* с этой оценкой.
   - Это «сеть, которая сама научилась». Сравнение с Kociemba: длина решения, время, доля решённых. Цифры честно в паспорт, даже если сеть хуже.
3. **2×2** — оптимальные решения полным перебором (BFS, около 3,7 млн позиций). Тест: сеть против оптимума.
4. **Послойный метод** — написанные правила, для режима «Учусь».

- **«Мысли ИИ»:** оценка сети «осталось ~N ходов» и сколько позиций просмотрено.

## 3. Проверки

- Модель куба: каждый ход и обратный ему возвращают состояние, 4 одинаковых поворота — тождество, известные порядки (например, (R U) имеет порядок 105).
- Решения Kociemba на 1000 случайных кубиках: все собирают куб, средняя длина ≤ 22.
- Сеть: доля решённых и средняя длина на 1000 случайных, время.
- Проверка возможности состояния: все виды «невозможных» кубиков ловятся.
